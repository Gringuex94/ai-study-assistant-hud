Visita guiada

Una ventana flotante que corrige mientras practicás

Es una aplicación de escritorio para Windows hecha en Python con CustomTkinter. Ve la pantalla como la ves vos, entiende la pregunta con un modelo de visión y te devuelve la opción correcta en letras grandes.

Cada captura se guarda en un historial, así podés repasar al final qué respondió para cada una.

Dos botones y una zona

Elegís qué parte de la pantalla mirar (la mitad izquierda o la pantalla completa) y tocás un botón.

InicioModo rápido. Captura la zona elegida y marca la opción de cada pregunta visible.
AvanzadoMás razonamiento: más lento, pensado para preguntas difíciles. Si no está disponible, usa Inicio.
ExplicaciónSe muestra u oculta con un botón y solo se genera si la pedís.

El recorrido de una captura

  1. Botón o atajoInicio, Avanzado, o los atajos F8 y F10 con la librería keyboard.
  2. Captura de pantallamss toma la zona elegida del monitor.
  3. Imagen en memoriaSe comprime a JPEG con BytesIO, sin archivos temporales.
  4. Modelo de visiónLa API de Gemini lee las preguntas y responde con un formato fijo.
  5. Parseo y pantallaUna expresión regular extrae las letras y el HUD las muestra.

Qué hay que resolver para que se sienta ágil

  • La ventana no se congela. La consulta a la nube corre en un hilo aparte y la interfaz se actualiza desde el hilo principal.
  • La API a veces se satura. Ante un error 503 o 429 pasa enseguida al siguiente modelo y deja al saturado en pausa 5 minutos.
  • Velocidad o precisión. El modo rápido reduce el razonamiento del modelo; el cuidadoso lo amplía.
  • Menos texto, menos espera. La explicación se pide aparte, reutilizando la imagen guardada.

Qué se envía y cómo se cuida

  • La clave de API vive en un archivo .env que no se sube al repositorio.
  • Se envía a la API de Gemini la zona elegida (por defecto, la mitad izquierda). Con pantalla completa se envía todo lo visible: no captures datos personales.
  • Los atajos globales se limitan a tres teclas y la app no registra lo que escribís.
  • Está pensado para estudiar y practicar, no para evaluaciones donde la ayuda externa esté prohibida.
